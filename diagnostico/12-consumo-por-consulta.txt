# Método:
#   1. pg_stat_statements ligado só para este diagnóstico, por ALTER SYSTEM SET shared_preload_libraries = 'pg_stat_statements'
#      + restart do banco + CREATE EXTENSION (fica no volume do banco; nenhum arquivo do repositório mudou).
#   2. Aquecimento igual ao do scripts/medir.sh (VUS=5, 15s, SEMENTE=43), depois pg_stat_statements_reset().
#   3. Uma rodada da carga com os parâmetros das medições (VUS=20, DURACAO=60s, SEMENTE=42), chamando o k6 direto
#      (docker compose run carga), sem o medir.sh: não gera pasta em resultados/ e NÃO é resultado de experimento.
#   4. Consulta abaixo em pg_stat_statements.
#
# Como ler:
#   - total_s/pct = tempo decorrido dentro do banco (total_exec_time), não CPU pura. Com até 10 consultas ao mesmo tempo
#     disputando 1 CPU, esse tempo inclui a espera pela CPU. Como o banco ficou em ~100% de CPU, a proporção é um indicativo
#     de onde a CPU vai, não uma medida exata.
#   - top-produtos usa processos paralelos (Workers Launched: 2 no diagnostico/08 e 10); o tempo dos workers não entra no
#     total_exec_time do processo principal, então o consumo real de CPU dessa consulta tende a ser maior que o mostrado.
#   - blocos_lidos = shared_blks_hit + shared_blks_read (páginas de 8 kB lidas do cache ou do disco).
#
# Consulta -> rota:
#   SELECT pr.id, pr.nome ... sum(...)              -> /relatorios/top-produtos
#   SELECT p.id AS pedido_id, p.criado_em, ...      -> /relatorios/vendas-por-dia
#   SELECT * FROM pedidos WHERE status ... OFFSET   -> /pedidos?status= (página)
#   SELECT count(*) ... WHERE status                -> /pedidos?status= (total)
#   SELECT * FROM produtos WHERE nome ILIKE         -> /produtos/busca
#   SELECT * FROM clientes WHERE id                 -> /clientes/:id e /clientes/:id/pedidos
#   SELECT * FROM pedidos WHERE cliente_id          -> /clientes/:id/pedidos
#   SELECT * FROM clientes WHERE lower(email)       -> /clientes?email=
#   SELECT * FROM produtos WHERE id                 -> /clientes/:id/pedidos (N+1, uma por item)
#   SELECT * FROM itens_pedido WHERE pedido_id      -> /clientes/:id/pedidos (N+1, uma por pedido)
